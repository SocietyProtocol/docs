# SPEC Token & Contribution Mechanics

The **SPEC Token** (`0x6AcD7735B3acF0DD677332a599FFfF71C18818BA`) is the stored value token of the Society Protocol movement.

---

## ⚡ Role of the SPEC Token

Unlike typical speculative tokens, SPEC performs four distinct functions within the Web3 Outpost ecosystem:

1. **Contribution Storage Metric:** Quantifies an account's historical contribution to building Society Protocol in an objective, verifiable standard.
2. **Access to VIP Channels:** Locking SPEC tokens mints Bronze (`14`), Silver (`15`), or Gold (`16`) VIP badges for exclusive, spam-free communication channels.
3. **Genesis Energy Claims:** Serves as the primary reference for upstart Web4 SP instances to allocate initial Energy distributions.
4. **Treasury & Runway Reserve:** ~27% of the SPEC token supply is retained by the SP DAO Treasury to fund multi-decade protocol development and engineering.
