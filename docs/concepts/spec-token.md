# SPEC Token: Objective Contribution & Economics

The **SPEC Token** (`0x6AcD7735B3acF0DD677332a599FFfF71C18818BA`) is the objective contribution storage token of the Society Protocol movement. It works alongside the account system to provide a real-time, sybil-resistant community map on Ethereum.

---

## ⚖️ Subjective vs. Objective Contribution

To understand how the Web3 Outpost enables the launching of Web4 Society Protocol (SP) instances, contributions are separated into two distinct layers:

| Layer                       | System                           | Role in Web4 Genesis                                 | Example                                                                      |
| :-------------------------- | :------------------------------- | :--------------------------------------------------- | :--------------------------------------------------------------------------- |
| **Subjective Contribution** | **Accounts & Badges (ERC-1155)** | Determines **WHO** gets invited as Genesis Actors    | "Invite accounts with Builder Badge" or "Invite verified Argentine accounts" |
| **Objective Contribution**  | **SPEC Token (ERC-20)**          | Determines **HOW MUCH Energy** each account receives | "Allocate Energy proportional to SPEC balance" or "Equal Energy if SPEC > X" |

Together, Subjective Accounts and Objective SPEC holdings form a sybil-resistant community map. Upstart SP instances use this map to launch cohesive, legitimate instances populated by interested participants at scale.

## 🎯 Use Cases of the SPEC Token

### 1. Primary Use Case: Genesis Energy Allocation (~75 Year Horizon)

The primary function of SPEC is to be held as stored contribution value. Upstart Web4 SP instances recognize SPEC token holdings to allocate initial Energy distributions to legitimate participants. The Web3 Outpost remains active and valuable for decades to facilitate this launchpad transition.

### 2. VIP Rooms (Gold, Silver, Bronze)

Users lock SPEC tokens to enter exclusive, spam-free VIP communication channels. This allows committed participants to form long-term relationships and strategic partnerships.

### 3. Liquidity Provision (LP Rewards)

5% of the total SPEC supply (500,000,000 SPEC) is earmarked for liquidity providers in the SPEC/WETH pool, distributed evenly over a 5-year period.

### 4. Potential Future Outpost Features

- **Curation Mechanics:** Using SPEC for upvoting and curating forum and communication posts (implementing an infantile version of the Curation Value Function).
- **Encrypted Web3 Comms:** Payment for E2EE messaging storage and Web3 social media features (infantile Farming Value Function).
- **NFT Platform Extensions:** Access and discounts on custom avatar and flag collections for community differentiation.

## 🗳️ Governance Role: Parallel Feedback (Non-Voting)

To prevent sybil attacks and economic treasury capture (which plague traditional Web3 token-voting DAOs), SPEC is **not** used for direct execution voting in the SP DAO.

- **Meritocratic Governance:** Execution decisions are made exclusively by **Governor Badges** held by accountable core team members, advisors, and partner communities.
- **Community Parallel Feedback:** SPEC token holders can run parallel feedback votes on governance proposals. Governors review this feedback to gauge broader community sentiment before executing decisions.
- **Modular Decision Delegation:** In the future, Governors may delegate specific modular decision-making power to SPEC holders on a per-decision basis.
